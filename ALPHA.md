Channel: alpha. Not a beta. Not signed for AMO.

## Firefox

Standard Release will only load the unsigned XPI as a Temporary Add-on via about:debugging. Developer Edition / Nightly can set `xpinstall.signatures.required` to false for a sticky install. Android Firefox needs a signed build.
